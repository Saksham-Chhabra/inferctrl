## 1. System Vision & Architecture

INFERCTRL is an autonomous inference control plane and routing layer for LLM applications. It observes serving workloads, characterizes drift, evaluates routing and serving configurations across Gemini, Ollama, and simulated hardware, enforces deterministic Service-Level Objectives (SLOs), and safely promotes changes using canary rollouts with sub-second automated rollbacks.

## 2. Core Implementation Conventions & Rules

### Non-Negotiable Principle: Measurement Attribution
Never fabricate or blur metrics. Every recorded latency, token count, cost, and quality metric **MUST** carry an explicit `MeasurementSource`:
- `actual`: Monotonically measured wall-clock time (`time.perf_counter()`).
- `provider_reported`: Metrics directly reported in the upstream provider's API payload (e.g. Gemini `usageMetadata`, Ollama `prompt_eval_duration`).
- `estimated`: Calculated values based on pricing tables:
  $$\text{estimated\_cost} = \frac{\text{input\_tokens} \times \text{input\_rate} + \text{output\_tokens} \times \text{output\_rate}}{1{,}000{,}000}$$
- `simulated`: Values generated by the discrete-event physics engine.

### Deterministic Authority
- LLM agents propose hypotheses and inspect workloads.
- Non-LLM deterministic code (the Safety & Policy Engine and Gateway Routing Engine) enforces hard constraints and executes mutations.
- If quality information is not verified, `quality_verified` must be `False`. Never fabricate verified status.

### Privacy by Default
- Never log authorization headers, API keys, or full raw prompts to persistent storage.
- Request observability stores prompt length, token counts, and truncated previews (`[:40]`) by default.

## 4. Environment Variables

Create a `.env` file in the project root:

```env
# Google Gemini API Key (optional — falls back cleanly if not set)
GEMINI_API_KEY=your_gemini_api_key_here

# Ollama Local Daemon URL (optional — default: http://localhost:11434)
OLLAMA_BASE_URL=http://localhost:11434

# System Mode
INFERCTRL_MODE=development
```
